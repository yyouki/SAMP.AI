# Changelog

Notable changes for each published SAMP.AI version.

## 0.1.0 — Initial release

- Added the TypeScript core for tool registration/execution, schema validation, permissions, agent contracts, and provider integration.
- Added the adapter framework, mock game adapter, task queue, authenticated HTTP gateway, and typed Pawn action contracts.
- Added the reference Pawn filterscript for SA-MP and open.mp.
- Added player-specific object preview/edit orchestration with approval-gated apply flow.
- Added linked English and Indonesian documentation.
- Added GitHub Actions validation, TypeScript builds, Pawn compilation for both targets, and release bundle packaging.

This is an early reference integration release. Successful compilation does not imply live testing on a game server, and the bundle is not a complete hosted AI application or one-click installer.
