# Documentation Languages

> **Language:** [English](LANGUAGES.md) | [Bahasa Indonesia](id/LANGUAGES.md) · [Documentation index](INDEX.md)

SAMP.AI documentation is available in English and Bahasa Indonesia. English is the canonical technical source; Indonesian pages provide localized guidance while preserving API and protocol identifiers.

| Language | Main entry point |
|---|---|
| English | [README](../README.md) |
| Bahasa Indonesia | [README Indonesia](id/README.md) |

File names, API names, action IDs, capability names, permissions, schema names, enum values, and JSON fields remain unchanged. Behavioral changes should update both language versions in the same change. Additional languages can use a new directory such as docs/es.

Browse the [English index](INDEX.md) or [Indonesian index](id/INDEX.md).
